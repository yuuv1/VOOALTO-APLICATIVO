Como usar o Vooalto V7

Três módulos integrados: crie a ficha, catalogue a produção e envie orçamentos.
📋
1 · Ficha Técnica

Crie a ficha de produção no Ficha Técnica: dados do cliente, modelos, valores, cores e imagens. Quando terminar, clique em Enviar para Catalogação (embaixo). O número da ficha avança sozinho.

🏠
2 · Catalogação

Acompanhe todas as fichas em produção: a prioridade sobe sozinha com os dias (Média/Alta). Abra o PDF, marque ✔ Concluído quando terminar, ou clique em ✏️ Modificar Ficha para voltar ao editor (a ficha é atualizada na hora, sem duplicar).

💰
3 · Orçamento

Crie orçamentos/propostas com itens, valores, cliente e assinatura. O conteúdo é salvo automaticamente neste navegador — feche e volte que continua de onde parou. Use Salvar .json para guardar um arquivo.

🎨
Tema

O seletor no topo muda o tema do sistema inteiro (todos os módulos + barra).

💾
Backup

Em Catalogação use Exportar backup / Importar. O import pergunta se quer mesclar ou substituir — nada é apagado sem sua confirmação.
