Ou o aparelho está sem internet, ou o site está sendo atualizado. Toque no botão abaixo:

Abrir o VOOALTO

Para usar offline no celular: abra o sistema, use o menu do navegador e escolha “Instalar app” (Android/Chrome) ou “Adicionar à Tela de Início” (iPhone/Safari).

Como o site fica no ar

  1. O app é publicado em supabase.co/functions/v1/site.
  2. O código novo chega pelo GitHub (main) — não precisa reenviar nada.
  3. Os dados (fichas, orçamentos) ficam no navegador do aparelho.
