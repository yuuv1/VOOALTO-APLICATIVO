💰 Ajuda — Orçamento

Monte a proposta clicando na própria folha. Tudo é salvo automaticamente neste navegador.

Itens e valores

  • Preencha os campos do item na lista à esquerda (modelo, tecido, descrição, quantidade, valor). Tab pula para a próxima caixa e Shift+Tab volta — sem parar nos botões ⧉/✕. Na folha A4 vale o mesmo, de célula em célula. Enter também avança e, no último campo do item, cria um item novo.
  • O Total geral (acima da lista) soma os itens de todas as páginas.
  • Para marcar um trecho, selecione o texto e use Amarelo / Vermelho / Azul.

Páginas

  • ➕ Add Página cria uma página nova · ⧉ Duplicar copia a atual (ótimo para propostas parecidas) · ❌ Rem. Página tira a última.

Rascunho e arquivo

  • 💾 Salvar Atual Como Rascunho guarda uma cópia dentro do sistema (lista de rascunhos) — use para comparar versões.
  • O que você está editando é salvo sozinho a cada alteração (veja o selo 💾 Salvo HH:MM no topo).
  • 💾 Exportar tudo (com rascunhos) baixa um único arquivo .json com todos os rascunhos de orçamento, a proposta atual e todas as fichas salvas; 📂 Importar .json restaura tanto orçamentos individuais quanto o backup completo sem perder nada.

Assinatura

  • ✍️ Desenhar (mouse/dedo), 📤 Upload Imagem (PNG/JPG) ou 🔄 Restaurar Padrão para voltar à assinatura original.

Impressão

  • 📄 Imprimir / Salvar PDF: saem só as folhas A4 da proposta (painel e botões não imprimem).
  • 📸 Exportar Imagem (PNG) gera uma imagem da proposta para enviar no WhatsApp.

Atalhos

  • Ctrl+Z desfazer · Ctrl+Y (ou Ctrl+Shift+Z) refazer — vale para o orçamento inteiro.
  • Clique no cartão de um item (no número #1, por exemplo) para selecioná-lo. Aí: Ctrl+C copia o item, Ctrl+X recorta, Ctrl+V cola um igual e Delete apaga.
  • Tab / Shift+Tab próxima caixa / caixa anterior (lista de itens e folha A4) · Enter próximo campo · Ctrl+P imprimir/salvar PDF · Esc solta a seleção e fecha as janelas.
